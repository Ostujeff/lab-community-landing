# Тайм-бокс и границы имитации

## Цель

Явный список «делаем по-настоящему / имитируем» с обоснованием. Согласуется с критериями оценки.

## Вход

- `00-monad.md` — раздел 8

## Что произвести

### Делаем по-настоящему (оценивается)

| Что | Обоснование | Артефакт |
|---|---|---|
| Рыночный ресёрч | Понимание рынка AI-сообществ — вес #1 | `instructions/10-market-research.md` |
| Продуктовая модель и экономика | Превращение ТЗ в продукт — вес #2 | `instructions/11-product-spec.md` |
| Все тексты сайта | Реальные тексты — главный предмет оценки | `instructions/12-copy.md` → вёрстка |
| Попадание в стиль glebkudr.com | Стиль 1-в-1 — пункт ТЗ | `instructions/20-design-system.md` |
| Рабочая форма + TG-бот + БД | Форма → лиды — пункт ТЗ | `/lab/api/apply`, `leads.db`, Telegram |
| Живой деплой | Выложено на сервер — пункт ТЗ | `https://workisfun.ru/lab`, Docker Caddy + systemd |

### Имитируем (не оценивается, дёшево)

| Что | Как имитируем | Почему можно |
|---|---|---|
| Оплата | Кнопки тарифов → `/apply` или Telegram | Нет реального эквайринга в ТЗ |
| Архив разборов | Описан как механика, без бэкенда | Контент накапливается со временем |
| Голосование за темы | Описано в продукте, без бэкенда | Механика есть на ai-community |
| Защиты / демо-дни | Описаны в ритме, без стриминга | Формат, не инфраструктура |
| Резиденты | Категории экспертизы, без имён | Архетипы, не эндорсменты |
| Дипломы | 4 архетипа-иллюстрации | Без фейковых кейсов |
| Оферта / политика | Ссылки на glebkudr.com | Заглушки в стиле оригинала |
| Админка лидов | SQL-правки в БД | По решению в монаде |

### Принцип тайм-бокса

Тест не оплачивается → тайм-боксим инфраструктуру и имитации.
Глубина копирайта и продукта вознаграждается → инвестируем в тексты и модель.

Это решение — сигнал зрелости; проговорить в `33-submission.md`.
