## Цель

Полная непротиворечивая спецификация продукта «сообщество / лаборатория». Покрывает все пункты ТЗ.

## Что произвести

### Модель «лаба / диплом»

| Метафора | Реализация |
|---|---|
| Лаборатория | Сообщество (бренд Глеба) |
| Резидент лаборатории | Участник активного ядра |
| Научный руководитель | Глеб |
| Дипломный проект | Реальный AI-продукт, доведённый методом Контекст→Спецификация→Агент→Ревью→Продукт |
| Защита | Регулярные демо-дни |
| Резидент-эксперт | Приглашённый практик (модель RC) |
| Устав лаборатории | Контракт вовлечённого участия |

### Жизненный цикл участника

```
Заявка → Отбор (собеседование) → Онбординг (устав, проект) →
Работа над дипломом (еженедельный ритм) → Защита (демо) → Алюмни
```

**Статусы воронки (БД):** `new → screening → interview → invited → paid → active`
Терминальные: `rejected / lost / churned`

### Роли

| Роль | Описание |
|---|---|
| Резидент | Активное ядро. 10 000 ₽/мес + устав. |
| Вольнослушатель | Пассив разрешён. 20 000 ₽/мес. Без диплома и обязательств. |
| Резидент-эксперт | Приглашённый практик на 1–2 встречи. |
| Команда (B2B) | Несколько мест для компании. |

### Устав участия — обязательства резидента

1. Ведёт дипломный проект с **видимым прогрессом** (еженедельно)
2. Выступает спикером **≥1 раза в 6 месяцев**
3. Вносит лабораторный труд под брендом сообщества (минимум один из):
   - хостинг встреч
   - study-group
   - организация резидентов
   - ведение архива
   - менторство новичков
4. Подписывает устав при вступлении

### Устав — права вольнослушателя

1. Может посещать встречи без обязательств
2. Не ведёт диплом, не выступает, не вносит труд
3. Платит дельту (~×2) — «цена неучастия»
4. Может конвертироваться в резидента

### Недельный ритм

Один повторяющийся «лабораторный семинар», ротация по месяцу:

| Неделя | Формат |
|---|---|
| 1 | Разбор рабочего процесса участника |
| 2 | Мастер-класс |
| 3 | Приглашённая звезда (резидент) |
| 4 | Защита / демо |

### Механика голосования за темы

- Резиденты предлагают темы (разбор, мастер-класс, звезда)
- Голосование в закрытом чате (имитация на этапе теста — описана как механика, без бэкенда)
- Повестку не диктует один человек

### Экономика

- Интейк: **роллинг** (вступление в любой момент после отбора)
- Оплата: после приглашения (имитация — кнопки ведут на форму/Telegram)
- Команда: по запросу, B2B-воронка Глеба
